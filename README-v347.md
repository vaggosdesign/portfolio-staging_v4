# Portfolio v347 — Stable Product impact chart

This release simplifies the vertical Product impact widget without changing the four reported project results. The permanent subtitle and multi-line detail description have been removed. A fixed-height, single-line detail strip now changes only its text, not its dimensions.

Hover, focus or tap a bar to show a concise result and a case-study link. Bars are labelled Supply chain, HCL, Risk Radar and bnbme. Labels and selected values remain accessible to keyboard and touch users.

The site continues to include the Webflow asset migration files, and externally hosted media still needs localising before removing Webflow hosting.
